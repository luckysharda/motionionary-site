# Motionionary

A motion design studio portfolio and creator reference library. The site is a static Next.js export for Cloudflare Pages.

## Local development

```sh
npm ci
npm run dev
```

Create a production export with `npm run build`; the static site is written to `out/`.

## Media and attribution

The locally hosted LemoLab “Glass Product” film and its poster are credited under `public/references/ATTRIBUTION.txt`. The creator gallery links to the original creators and posts; those third-party videos remain on their source platforms and are not republished here.
