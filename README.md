# Motionionary

A motion design studio portfolio featuring original, self-directed concept studies and client services. The site is a static Next.js export for Cloudflare Pages.

## Local development

```sh
npm ci
npm run dev
```

Create a production export with `npm run build`; the static site is written to `out/`.

## Portfolio content

The portfolio currently features original concept artwork. Add client work only when it is yours to show and you have permission to publish it.

See [DEPLOYMENT.md](./DEPLOYMENT.md) for the GitHub Actions setup and Cloudflare Pages secret required for production deploys.
